## 最迫切需要解决的问题

### 1. TTS 替换为本地服务
- **问题**: 原用 OpenAI TTS，需要 API key 且收费
- **解决**: `app/api/voice/tts/route.ts` 改为调用 `http://192.168.3.186/speak`，透传音频二进制
- **注意**: text_lang 固定 `"en"`，暂不支持中文语音合成

### 2. STT 语音识别报 OPENAI_API_KEY not configured
- **问题**: 原用 OpenAI Whisper 做语音转文字，需要 API key
- **解决**: 改为浏览器原生 Web Speech API（`SpeechRecognition`），零成本无需后端
- **影响文件**: `app/page.tsx`、`components/ChatInput.tsx`、新增 `speech.d.ts` 类型声明

### 3. AI 对话 401 认证错误（核心 bug，踩坑多次）
- **根因 1**: 代理 `api.antmoo.com` 是 **OpenAI 兼容格式**，用 Anthropic SDK 调不通
- **根因 2**: 系统环境变量 `ANTHROPIC_BASE_URL` 指向火山引擎 `ark.cn-beijing.volces.com`，覆盖了 `.env.local` 的值
- **解决**:
  - 去掉 Anthropic SDK 和 OpenAI SDK，改用原生 `fetch` 调代理的 `/v1/chat/completions`
  - 环境变量改名 `HIM_ANTHROPIC_API_KEY` / `HIM_ANTHROPIC_BASE_URL`，避免系统变量覆盖
  - `lib/ai.ts` 完全重写：`createClient` → `chatRequest`，统一用 fetch

### 4. 首页输入跳转后对话页不显示用户输入
- **问题**: React Strict Mode 下 `useEffect` 执行两次，第二次 fetch 的 `setMessages([])` 覆盖了 `sendMessage` 添加的消息
- **解决**: `useEffect` 开头加 `if (firstSent.current) return;` 守卫

### 5. .next 缓存损坏
- **问题**: 启动报 `ENOENT: no such file or directory, vendor-chunks/tailwind-merge.js`
- **解决**: `rm -rf .next` 清缓存后重启

### P0 — 首页输入"你好"跳转对话页后，用户消息仍可能不显示
- **状态**: 已加 `firstSent` 守卫，需验证是否完全修复

## 角色系统设计

- **文件**: `lib/roles.ts`
- **当前角色**: `therapist` — 温暖、共情的心理咨询师
- **system prompt 核心规则**:
  - 使用 CBT / ACT / 以人为中心疗法
  - 不诊断、不开药
  - 用户有自伤/自杀倾向时引导专业帮助
  - 回复格式：英文段 + 空行 + 中文段，不加 "English:" / "Chinese:" 标签
- **扩展方式**: 在 `ROLES` 对象中加新角色，对话创建时传 `roleId` 即可切换
