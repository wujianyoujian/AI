方案1 原生 loading="lazy"

浏览器内置懒加载，仅需一个 HTML 属性，零 JavaScript。浏览器自动决定何时加载（通常在视口附近）。
适用：追求简洁，无需精细控制加载时机的场景。

<!-- 仅需添加 loading="lazy" 属性 --> <img src="image.jpg" loading="lazy" alt="...">

方案2 Intersection Observer API

使用 data-src 存储真实地址，进入视口时替换。可精细控制 rootMargin（提前量）和 threshold（可见比例）。
适用：需要精确控制、配合骨架屏/动效的场景（推荐方案）。

const observer = new IntersectionObserver((entries) => { entries.forEach(entry => { if (entry.isIntersecting) { const img = entry.target; img.src = img.dataset.src; // 替换真实地址 img.removeAttribute('data-src'); observer.unobserve(img); // 停止观察 } }); }, { rootMargin: '100px' }); // 提前 100px 触发 document.querySelectorAll('img[data-src]') .forEach(img => observer.observe(img));

方案3 CSS 背景图懒加载

背景图无法使用 loading="lazy"，通过 Intersection Observer 动态添加 class，触发背景图加载。
适用：卡片封面、Banner 等使用 CSS background-image 的元素。

/* CSS：默认无背景图，loaded 后才添加 */ .bg-lazy { background-image: none; } .bg-lazy.loaded { background-image: url('real-bg.jpg'); } // JS：进入视口时添加 loaded class if (entry.isIntersecting) { entry.target.style.backgroundImage = `url(${entry.target.dataset.bg})`; entry.target.classList.add('bg-loaded'); }

方案4 scroll 事件监听（兼容方案）

监听 window scroll 事件，用 getBoundingClientRect() 判断是否进入视口。性能差，需节流，仅用于需兼容旧浏览器（IE11）的场景。
注意：每次滚动都触发计算，务必配合 throttle 使用。

function isInViewport(el) { const rect = el.getBoundingClientRect(); return rect.top <= window.innerHeight + 100; // 提前 100px } let timer; window.addEventListener('scroll', () => { if (timer) return; // 节流：200ms 内只执行一次 timer = setTimeout(() => { lazyLoad(); timer = null; }, 200); });

方案5 缓存懒加载（内存缓存 + Cache API）

相同资源只请求一次，之后命中缓存直接读取，无网络请求。
内存缓存（Map）：用 Map<url, ObjectURL> 存储当前 session 的 Blob，刷新后失效。
Cache API：存入浏览器 Cache Storage，跨页面、跨刷新持久有效，类似 Service Worker 缓存。

// ① 内存缓存：用 Map 存 ObjectURL，同一页面内命中 const memCache = new Map(); if (memCache.has(url)) { img.src = memCache.get(url); // 直接复用，无请求 } else { const blob = await fetch(url).then(r => r.blob()); const objectUrl = URL.createObjectURL(blob); memCache.set(url, objectUrl); // 存入 Map img.src = objectUrl; } // ② Cache API：持久化存储，刷新后仍命中 const cache = await caches.open('my-img-cache'); const cached = await cache.match(url); if (cached) { img.src = URL.createObjectURL(await cached.blob()); } else { const response = await fetch(url); await cache.put(url, response.clone()); // 存入 Cache Storage img.src = URL.createObjectURL(await response.blob()); }
