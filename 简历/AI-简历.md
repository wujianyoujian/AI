## 项目经历

### 支付宝五福 · 手机互碰营销玩法
**项目背景：** 春节五福是支付宝年度最大营销活动，本玩法为用户通过 NFC 双端碰一碰完成实时配对拉新出红包领奖励（H5 内嵌支付宝 WebView，通过支付宝 JSAPI 调起 NFC 能力）。需同时覆盖 iOS，Android，鸿蒙三端。

**角色：** 核心交互模块 Owner，负责功能设计开发，状态管理与全链路性能优化。

**技术栈：** React + Zustand + Umi + Antd-Mobile + @galacean/effects (Mars 引擎)

**核心贡献：**
- NFC 游戏状态机：设计基于 Zustand 的 7 阶段状态流转（权限检测 → 引导拦截 → 开始游戏 → 碰撞中 → 配对查询 → 出奖 → 异常兜底），解决三端权限 API 不一致及网络抖动下的双端配对同步问题；引入游戏计时器按时间窗口动态引导，提升用户操作成功率。
- 动画分级降级：基于 navigator.hardwareConcurrency、deviceMemory 与 UA 综合评分，在首帧渲染前完成高/中/低三档降级决策，低端机帧率 30fps → 55fps+，无视觉跳变。
- 资源加载优化：CDN 预缓存 + 接口预请求 + 按阶段懒加载，FCP 4.5s → 2.0s；建立实时性能监控与异常自动上报，活动全程 14 天 0 客诉。

**技术难点：** 三端 NFC 权限 API 差异大，需统一抽象层抹平 iOS/Android/鸿蒙不一致；双端碰一碰后异步出奖存在时序竞态，通过状态机 + 超时轮询保证配对可靠性；低端机 Mars 动画帧率不足 30fps，硬件评分分级降级后稳定 55fps+。

**项目成果：** 活动峰值 300w+ PV / 100w+ UV，支付宝 NFC 功能打开率提升 10%+，14 天活动期间 0 客诉 0 P 级问题。
