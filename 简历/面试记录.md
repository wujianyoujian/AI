#### http版本区别

* http 0.9 
  1. 只有get请求
  2. 无状态，无请求头，响应头
  3. 只支持纯文本协议，一个请求一个tcp 连接

* http 1.0
  1. 支持请求头，响应头
  2. 状态码
  3. 支持多个文件类型

* http 1.1
  1. 支持长连接，keep-alive，
  2. 管线化，支持一个请求响应之前，发送另一个请求
  3. 缓存增强，cache-control，ETag，If-None-Match
  4. Range 支持断点续传，和分片下载
* http 2.0
  1. 二进制分帧
    [HEADERS 帧 stream=3 : path=/style.css]
    [DATA 帧 stream=3 : "body { color:"]
    [HEADERS 帧 stream=5 : path=/script.js]
    [DATA 帧 stream=5 : "var x = 1;"]
    [DATA 帧 stream=3 : " red; }"]
  2. 多路复用，根据 二进制分帧，根据流 id，还原出完整的请求和响应
  3. 支持服务器推送

* http 3.0

#### cdn 原理，回源等

> cdn 是啥
* 内容分发网络，把资源缓存到离用户最近的节点
目的：减少网络延迟，TCP 连接耗时，提高首屏速度
流程

1. 一个cdn静态资源，会先进行dns 解析，浏览器缓存，操作系统缓存，运营商DNS，根据 CNAME 记录访问 CDN调度域名
2. cdn 服务商的权威DNS 服务器（GSLB 智能dns） 调度 会根据请求IP地址，运营商，集群负载 计算出一个最优的边缘节点IP，返回A记录，客户端就获取到了离它最近的CDN 边缘节点IP地址
3. 建立 TCP 连接，进行HTTP 请求
4. 边缘节点 解析请求 检查缓存，缓存没有过期 使用缓存返回，
5. 缓存不存在，回源，向源站请求资源，源站返回，边缘节点收到，缓存返回客户端

主动预热，就是提前讲资源分发到各个节点，重大更新, 其实也是主动回源
