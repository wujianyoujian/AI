### 14:30-16:00 | 浏览器 + 网络 + 安全（1.5h）

只记核心区别，不记细节：

| 知识点 | 只记这一句话 |
|--------|------------|
| 重排/重绘/合成 | 重排一定触发重绘和合成；`transform` 只触发合成 |

## 傍晚：JS/TS/CSS 基础速刷（1.5h）

### 16:00-17:30

不要重学，只过你最可能卡住的点：

- **闭包 → 内存泄漏定位**：Heap Snapshot → Comparison 视图 → Detached DOM → Retainer 路径
- **this**：箭头函数没自己的 this（定义时确定）、普通函数看调用方式、`bind` 返回新函数
- **原型链**：`obj.__proto__` = `Constructor.prototype`；`Function.__proto__` = `Function.prototype`（特例）
- **TS 工具类型**：`Pick<T, K>` / `Omit<T, K>` / `Partial<T>` / `Required<T>` / `Record<K, V>` / `ReturnType<T>`
- **BFC**：解决 margin 塌陷和清除浮动；触发条件 overflow/float/position/display
- **垂直居中**：Flex（`align-items: center` + `justify-content: center`）是最短答案
