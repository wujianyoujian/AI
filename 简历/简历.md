### 支付宝五福·手机互碰营销玩法

  春节五福核心玩法，NFC 双端实时配对拉新，覆盖 iOS / Android / 鸿蒙三端。活动峰值 **300w+ PV / 100w+ UV**，支付宝 NFC 功能打开率提升 **10%+**。

  **角色**：核心交互模块 Owner，负责功能设计开发，状态管理与全链路性能优化。

  技术栈：`React` + `Zustand` + `Umi` + `Antd-Mobile` + `@galacean/effects (Mars引擎)`

  **1. NFC 游戏状态机设计（解决多端权限 + 流程异常问题）**

  NFC 互碰涉及 NFC / 定位 / 蓝牙 / 支付宝版本等多维度权限前置校验，且 iOS、Android、鸿蒙三端权限 API 行为不一致，加上网络异常、配对超时、单边碰成功等边界态，简单的 if/else 流程极易产生状态逻辑混乱。
  设计基于 Zustand 的 **有限状态机（FSM）** 的游戏流程管理器，状态流转：权限检测 → 引导拦截 → 开始游戏 → 碰撞中 → 配对查询 → 出奖 → 异常兜底
  - 配对结果通过轮询接口获取，设计**广播同步机制**：任意一方碰撞成功，对端自动同步出奖，解决网络抖动下的双端一致性问题
  - 引入游戏计时器，按时间窗口动态下发引导提示（如"靠近对方手机"，"未找到好友等"），提升用户操作成功率

  **2. 动画性能分级降级（低端机帧率 30fps → 55fps+）**

  Mars 引擎 动画在低端机上帧率跌至 ~30fps，且发热明显。设计**设备性能分级策略**：

  - 封装自动降级API，按分位线划分高 / 中 / 低三档
  - 高端机：多个动画；中端机：2D 序列帧动画；低端机：静态降级图片兜底
  - 降级决策在首帧渲染前完成，**无视觉跳变**，低端机帧率稳定至 **55fps+**
