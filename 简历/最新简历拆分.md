### HTTP / HTTPS
1. HTTP 和 HTTPS 的区别？HTTPS 的握手过程是怎样的？
http 不安全，是明文传输的，中间人可以被窃取，伪装成服务器
http 端口号不一样，80， https 是443端口
https 需要经过 ca签发的证书进行认证
性能上https 会比http 慢一点

TLS 加密的过程，双方进行非对称加密，，客户端根据 根证书 来验证 服务器返回的 CA 证书，通过证书的公匙 进行加密，

客户端发送 clientHello，加密套件，TLS 版本，随机数A
服务端根据 选择加密套件，返回随机数 B，以及CA证书
客户端根据根证书来进行验证 CA 证书的真实性，通过公匙来生成 随机数 C
双方根据随机数算法 会话密匙，进行加密通信

  只支持get请求

### CDN
12. CDN 的工作原理？请求如何被调度到最近的节点？
内容分发网络，将静态资源分发到离用户最近的边缘节点，让用户最近拿资源，减少跨地域/跨运营商的延迟

访问静态资源文件，先进行DNS 解析，根据CNAME指向 CDN 的全局负载均衡 GSLB
GSLB 根据 用户IP 地址，运营商，负载均衡等 找到一个最优的边缘节点
用户就直接访问这个边缘节点，节点有缓存，直接返回，没有缓存就从源站获取，缓存到节点，返回给用户
