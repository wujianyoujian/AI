# 简历 MD → PDF 生成 Prompt

## Prompt 正文

你是一名专业的前端工程师 + 设计师，擅长将 Markdown 简历转换为精美的 PDF 简历。
请根据以下要求，生成一份完整可直接运行的 **单文件 HTML**，浏览器打开后通过 Ctrl+P 打印/保存为 PDF。

---

## 设计风格

**核心方向**：现代简洁，专业有质感，带一点点设计感——区别于模板感强的大众简历，但绝不花哨。

**视觉关键词**：`Editorial` / `高级灰` / `留白克制` / `排版驱动`

### 色彩方案

- 主色：`#1a1a1a`（正文深黑）
- 强调色：`#2563EB`（蓝色，用于姓名、标题左侧色块、技术栈 tag）
- 辅助色：`#64748B`（浅灰，用于时间、副标题）
- 背景：纯白 `#FFFFFF`
- 分割线：`#E2E8F0`

### 排版规范

- 字体：`-apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`，中英文混排
- 正文：`13px / 行高 1.75`
- 姓名：`28px bold`，左对齐
- Section 标题：`15px bold`，左侧带 `3px 蓝色竖线`，全大写英文 or 中文均可
- 时间、地点：右对齐，灰色小字
- 技术栈：小圆角 tag（`border: 1px solid #CBD5E1`，`padding: 1px 6px`，`border-radius: 4px`，`font-size: 11px`）

---

## 布局结构

```
┌─────────────────────────────────────────────┐
│  姓名（大）    岗位意向    联系方式（右对齐）     │
│  ─────────────────────────────────────────  │
│  个人能力（两列或单列段落）                      │
│  ─────────────────────────────────────────  │
│  工作经历                                      │
│    公司名 + 岗位（左） / 时间（右）              │
│    · 职责条目                                  │
│  ─────────────────────────────────────────  │
│  项目经历                                      │
│    项目名（强调色）+ 技术栈 tag                  │
│    项目简介（一行）                              │
│    · 技术亮点条目                              │
└─────────────────────────────────────────────┘
```

- 整体单栏，A4 尺寸（`width: 794px`，内边距 `48px 52px`）
- 各 Section 间距 `24px`，条目间距 `6px`
- 公司名用 `font-weight: 600`，项目名用强调色 + `600`

---

## 打印适配

```css
@media print {
  body { margin: 0; }
  @page { size: A4; margin: 0; }
  /* 避免条目被分页截断 */
  .item { break-inside: avoid; }
}
```

---

## 输入数据

请将以下 Markdown 简历内容渲染进 HTML：

```markdown
{{粘贴你的 简历.md 内容}}
```

---

## 输出要求

1. 输出**完整可运行的单文件 HTML**，所有样式内联在 `<style>` 中
2. 不依赖任何外部 CDN / 字体，确保离线可用
3. 代码结构清晰，Section 用语义化标签（`<section>`, `<header>`, `<ul>` 等）
4. 最终效果：浏览器直接打开，Ctrl+P → 另存为 PDF → 一页或两页，无截断，无白边
5. 不要加水印、页脚、页码

---

## 加分细节（可选，如果你想更有设计感）

- 姓名旁边放一个极简几何装饰（一个 `4px × 28px` 的蓝色矩形色块）
- 技术栈 tag 悬停 hover 时有微弱背景色变化（打印时不影响）
- 每个公司条目最左侧用 `border-left: 2px solid #E2E8F0` 做时间轴感
- 项目名前放一个 `◆`（`color: #2563EB`，`font-size: 9px`）作为小装饰符
